# BaitGuard — landing page

Spot the bait. Stay safe online.

Static landing page for BaitGuard, an interactive scam-simulation platform.
Plain HTML, CSS and JavaScript — no build step, served by GitHub Pages.

## Structure

    index.html          page markup
    styles.css          all styles
    main.js             hero rotator, scroll animations, interactive demo
    assets/brand/       logo + favicon
    assets/hero/        rotating hero photos (see assets/hero/README.md)

## Local preview

Open `index.html` directly, or run any static server, e.g.:

    npx serve .
